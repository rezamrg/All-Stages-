## ۱. سند نیازمندی‌های محصول (PRD)

### ۱.۱ قوانین رسمی و به‌روز Stage 1
- **شبانه‌روزی و ساعتی:** در تمام ۲۴ ساعت شبانه‌روز، پنجره‌های ۱ ساعته برگزار می‌شود (از دقیقه ۳۰ یک ساعت تا دقیقه ۳۰ ساعت بعد، مانند ۱۸:۳۰ الی ۱۹:۳۰).
- **۸ قسمت در هر پنجره:**
  1. قسمت اول: X:35
  2. قسمت دوم: X:45
  3. قسمت سوم: X:55
  4. قسمت چهارم: (X+1):05
  5. قسمت پنجم: (X+1):10
  6. قسمت ششم: (X+1):15
  7. قسمت هفتم: (X+1):20
  8. قسمت هشتم: (X+1):30
  - **رقابت اصلی (فینال):** ۵ دقیقه بعد از قسمت هشتم در (X+1):35.
- **خرید چیپ و ورودی:**
  - پایه: ۲۵ سنت = ۵,۰۰۰ چیپ.
  - گام‌های ۵ سنتی: ۵ سنت (۱,۰۰۰ چیپ)، ۱۰ سنت (۲,۰۰۰ چیپ)، ۱۵ سنت (۳,۰۰۰ چیپ)، ۲۰ سنت (۴,۰۰۰ چیپ)، ۲۵ سنت (۵,۰۰۰ چیپ).
  - کل ۸ قسمت با ۲۵ سنت = ۲ دلار.
- **مرحله مقدماتی ۳-کارت آل-این:**
  - میزهای تصادفی ۶ الی ۹ نفره با کارت‌های رو.
  - ۳۰ ثانیه برای حذف ۱ کارت و حفظ ۲ کارت (حذف خودکار ضعیف‌ترین در صورت اتمام وقت).
  - آل-این خودکار سیستم و انتقال برنده به همراه تمام چیپ‌های میز به فینال.
- **صعود و استک فینال:**
  - امکان ثبت‌نام مجدد در قسمت‌های بعدی همان پنجره برای کسب چیپ بیشتر؛ چیپ‌ها با هم جمع می‌شوند.
  - رقابت اصلی: تگزاس هولدم استاندارد، کارت‌های مخفی، بلایندهای ۵ دقیقه‌ای، زمان تقریبی ۲ ساعت.
  - جوایز ۹۰ نفر اول (رتبه ۱: $۱۴.۵۰ تا رتبه ۹۰: $۰.۵۰ با تضمین حداقل ۱۰۰ دلار سایت).

### ۱.۲ بازه زمانی و انعطاف‌پذیری تاریخ
- بازه پیش‌فرض: **چهارشنبه ۸ مهرماه ۱۴۰۵ تا چهارشنبه ۲۲ مهرماه ۱۴۰۵** (۱۵ روز، ۳۶۰ پنجره، ۲۸۸۰ قسمت ممکن).
- **امکان ویرایش آزادانه تاریخ شروع و پایان:** کاربر می‌تواند تاریخ و روز شروع و پایان را در هر لحظه تغییر دهد؛ سیستم بلادرنگ تمام محاسبات را بر اساس تاریخ جدید بازسازی می‌کند.

## ۲. معماری سیستم

معماری پروژه مبتنی بر اصول **Clean Architecture** و **Domain-Driven Design (DDD)** به صورت ماژولار پیاده‌سازی شده است:

```
src/
├── types/              # تعاریف داده و تایپ‌های TypeScript
│   └── poker.ts
├── utils/              # توابع محاسباتی، تقویم و قوانین
│   ├── calculations.ts # موتور ریاضی محاسبه سود، ضرر، همبستگی و زنجیره‌ها
│   ├── calculations.test.ts # تست‌های خودکار
│   ├── jalali.ts       # محاسبات تقویم شمسی بر پایه jalaali-js
│   └── pokerRules.ts   # جدول زمان‌بندی و جوایز Stage 1
├── services/           # لایه ذخیره‌سازی محلی و هوش مصنوعی
│   ├── storage.ts      # ذخیره‌سازی در LocalStorage، Seed اولیه و خروجی
│   └── aiService.ts    # تحلیل‌گر هوش مصنوعی Gemini 3.8 Flash + موتور محلی
├── components/         # کامپوننت‌های رابط کاربری
│   ├── Navbar.tsx      # نوبار استاندارد با شمارش معکوس پنجره فعال
│   ├── DashboardTab.tsx# داشبورد لحظه‌ای، نمودارها و مانیتور زنده
│   ├── HourlyWindowTab.tsx # کاوشگر ۲۴ ساعته پنجره‌ها
│   ├── DailyReportTab.tsx  # جدول روزانه و دوره‌ای
│   ├── AdvancedStatsTab.tsx# آمار پیشرفته و همبستگی
│   ├── AIAdvisorTab.tsx    # دستیار و چت تعاملی هوش مصنوعی
│   ├── DocumentationTab.tsx# مستندات داخلی نرم‌افزار
│   ├── QuickRegisterModal.tsx # مودال ثبت سریع و گروهی
│   ├── WindowDetailsModal.tsx # جزئیات پنجره و فینال
│   ├── DateRangeModal.tsx  # ویرایش بازه تاریخ شمسی
│   ├── SettingsModal.tsx   # تنظیمات کیف‌پول و حد ضرر
│   └── ExportModal.tsx     # خروجی Excel, CSV, PDF, JSON
├── App.tsx             # کامپوننت ریشه و مدیریت State
└── main.tsx
```

## ۳. مدل داده و ساختار APIها

### ۳.۱ مدل داده اصلی (Data Entities)
- `SessionWindow`: شناسه، تاریخ شمسی، تاریخ میلادی، ساعت شروع، ۸ قسمت بازی‌شده، نتیجه فینال، مجموع هزینه، مجموع چیپ، سود خالص.
- `SubRoundEntry`: شماره قسمت (۱ تا ۸)، ساعت دقیق، مبلغ ورودی (۵ تا ۲۵ سنت)، چیپ اولیه، وضعیت صعود، چیپ کسب‌شده، سایز میز.
- `FinalResult`: رتبه در فینال (۱ تا ۹۰+)، جایزه دریافتی ($)، مدت حضور (دقیقه)، استک اولیه.
- `DailyRecord`: مجموع پنجره‌های فعال، صعودها، هزینه، جایزه، سود روز، سود تجمعی، نرخ موفقیت.
- `UserSettings`: موجودی اولیه، واحد پول (دلار/تومان)، نرخ ارز، اهداف سود، سقف حد ضرر روزانه و دوره‌ای، بازه تاریخ شمسی.

### ۳.۲ مسیرهای API
- `POST /session-windows`: ایجاد یا بروزرسانی پنجره
- `GET /session-windows`: دریافت پنجره‌های بازه زمانی
- `POST /sub-round-entries`: ثبت زیرمرحله
- `GET /reports/daily`: دریافت گزارش روزانه
- `GET /reports/advanced-stats`: تحلیل همبستگی و ساعات طلایی
- `POST /ai/analyze-performance`: درخواست تحلیل هوشمند از Gemini 3.8 Flash
- `GET /export/excel` / `GET /export/csv` / `GET /export/json`: دریافت خروجی داده‌ها

## ۴. طرح UI/UX و سیستم دیزاین

- **تم دارک لوکس و بدون خستگی چشم:** پس‌زمینه زغالی (`#0a0b0e`)، مرزهای ظریف (`border-neutral-800`) و رنگ‌های متضاد استاندارد WCAG AA.
- **تایپوگرافی ویژه فارسی و اعداد جدولی:** قلم Vazirmatn همراه با JetBrains Mono (`tabular-nums`) جهت تراز دقیق ارقام دلاری و چیپ‌ها بدون لرزش رابط کاربری.
- **پشتیبانی کامل از موبایل (Responsive):** تمامی دکمه‌ها و فیلدها با ابعاد لمسی بهینه طراحی شده‌اند.

## ۵. تست‌های واحد

پروژه شامل تست‌های واحد خودکار برای تضمین صحت ۱۰۰٪ محاسبات مالی و زمان‌بندی است:
- محاسبه سود/زیان پنجره و هزینه تا اولین صعود
- محاسبه جوایز فینال بر اساس جدول پلکانی
- تبدیل دقیق تاریخ شمسی به میلادی و محاسبه طول دوره ۱۵ روزه
- محاسبه زمان دقیق هر یک از ۸ زیرمرحله بر اساس ساعت پنجره

اجرای تست‌ها:
```bash
npm test
```

## ۶. راهنمای نصب و اجرا

### پیش‌نیازها
- Node.js نسخه 20 یا بالاتر
- npm نسخه 10 یا بالاتر

### مراحل نصب
```bash
# ۱. کلون پروژه
git clone <repo-url>
cd <repo-name>

# ۲. نصب وابستگی‌ها
npm install

# ۳. اجرای سرور توسعه
npm run dev

# ۴. ساخت نسخه نهایی
npm run build
```

## ۷. کانتینری‌سازی با Docker

اجرا با یک دستور به کمک Docker Compose:
```bash
docker compose up -d --build
```
